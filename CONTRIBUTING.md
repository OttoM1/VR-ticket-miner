# Contributing to VR Ticket Miner

VR Ticket Miner is an open-source "vibe" project; bug reports, documentation improvements, and code changes are welcome.

## Table of contents

- [Code of conduct](#code-of-conduct)
- [Ways to contribute](#ways-to-contribute)
- [Pull request process](#pull-request-process)
- [Reporting issues](#reporting-issues)

## Code of conduct

Maintainers may close issues, reject pull requests, or restrict participation.

## Ways to contribute

- Report bugs with clear reproduction steps
- Suggest improvements or features
- Review pull requests and test proposed changes

## Pull request process

All contributions merge through **reviewed pull requests**. There is no direct push access for external contributors.

1. **Fork** the repository and create a branch from `main`.
2. **Commit** with clear messages that explain _why_ the change is needed.
3. **Open a pull request** against `main` with:
   - A concise summary of the change
   - Linked issue numbers (e.g. `Fixes #42`) when applicable
   - Notes on testing (commands run, mock vs live mode, etc.)

### Pull request checklist

- [ ] `npm run typecheck` passes
- [ ] `npm run lint` passes
- [ ] `npm run build` succeeds
- [ ] No unrelated formatting or drive-by refactors
